## Project Name
CI/CD Final Project - Automated Testing and Deployment

## Description
This project implements a Continuous Integration and Continuous Deployment (CI/CD) pipeline using GitHub Actions and OpenShift. It automates code quality checks, testing, and deployment processes.

## Technologies Used
- Python
- Flask
- GitHub Actions
- Flake8
- Nose
- Tekton
- OpenShift
- Docker

## Features
- Automated code linting with Flake8.
- Automated unit testing with Nose.
- Continuous Integration using GitHub Actions.
- Continuous Deployment pipeline.
- Containerization using Docker.
- OpenShift deployment support.

## CI/CD Pipeline
The GitHub Actions workflow automates the following steps:

1. Checkout the repository.
2. Set up the Python environment.
3. Install project dependencies.
4. Run static code analysis with Flake8.
5. Execute unit tests with Nose.
6. Report the workflow execution status.
